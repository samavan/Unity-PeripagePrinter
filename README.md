# Unity-PeripagePrinter

To support that tiny Peripage printer for Unity.

Partially Vibe-coded.

# Structure:
- Assembly Definition
- NameSpace
- #region
- Commented with other git repo used as ref
- Demo Scene with UI support

# Support
- Mac OS Unity Editor plugin is working.

- Android plugin to support Kiosk Touch Display:
```bash
rockchip rk3288 
Android OS 7.1.2 
API Level 25
```

# Contributing
It's free; have fun :) 

Ping me if you need more support with the tiny printer ^_^!

# SubModule in Unity:

```bash
[submodule "Unity/Assets/Packages/Unity-PeripagePrinter"]
   path = Unity/Assets/Packages/Unity-PeripagePrinter
   url = git@github.com:samavan/Unity-PeripagePrinter.git
```
